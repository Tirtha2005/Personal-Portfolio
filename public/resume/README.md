# Resume File Integration

To make your real resume downloadable directly from the portfolio website:
1. Save your resume as a PDF file named `resume.pdf`.
2. Place it right in this directory:
   `/public/resume/resume.pdf`
3. In `data/portfolio.ts`, change:
   `resumeAvailable: true`

The website will automatically link all "Download Resume" buttons to your actual PDF!
Until then, the website provides a comprehensive, interactive Resume Data Sheet modal preview that highlights your academic credentials, verified skills, and project summaries without fabricating documents.
